## Learning UX Review

**Overall status: FAIL for student-facing Learning UX.**  
Read-only review completed. No files edited.

| Criterion | Status | Finding |
|---|---:|---|
| `theoryNote` vs `playbackNote` / `auditionNote` distinction | PASS | The distinction is clear in both README and UI status labels. |
| No Month 5 or Month 7-8 preview wording | PASS | No Month 5 or Month 7-8 wording found. |
| Beginner-safe/private teacher terminology | FAIL | UI reads like an engineering diagnostic, not a Thai private guitar teacher. |
| No future capability implication | FAIL | README includes future-facing Sound Lab V2 wording; UI also uses `Min compare` / `Maj compare`, which implies theory comparison features. |

**Findings**

- `Theory Note` / `Playback Note` is structurally clear, but too technical for a beginner. Better Thai labels would be `โน้ตที่กำลังเรียน` and `เสียงที่เปิดให้ฟัง`.
- No Month 5 or Month 7-8 preview copy appears in `README.md` or `index.html`.
- `README.md` line 28 says “Future Sound Lab V2 may compare...”, which should be removed or rewritten because it hints at future capability.
- `README.md` line 30 mentions arpeggio only as a prohibition, so it is not a capability promise, but it should stay out of any student-facing copy.
- `index.html` uses diagnostic labels like `AudioContext`, `Synth (Fallback)`, `Sampler Status`, `Normalization`, `RAW - Bypassed`, and `Loudness Obs.`. These are not private-teacher language.
- `Min compare` / `Maj compare` should be avoided in beginner UI unless the lesson explicitly teaches that concept.

**Label Recommendations**

| Current label | Recommended label |
|---|---|
| `Audio Diagnostics` | `ทดสอบเสียง Sound Lab` |
| `Theory Note` | `โน้ตที่กำลังเรียน` |
| `Playback Note` / `Audition Note` | `เสียงที่เปิดให้ฟัง` |
| `Normalization` | `ปรับ octave ให้ฟังชัด` |
| `Loudness Obs.` | `ความชัดของเสียง` |
| `Unlock Audio Context` | `เริ่มระบบเสียง` |
| `Test Beep (Synth)` | `ลองเสียงสั้นๆ` |
| `Group A: Raw Low-Register Test` | `ฟังโน้ตต่ำแบบเดิม` |
| `Group B: Normalized Sound Lab Test` | `ฟังโน้ตที่ปรับให้ชัดขึ้น` |
| `RAW - Bypassed` | `เสียงเดิม ไม่ปรับ octave` |
| `Min compare` / `Maj compare` | `เทียบเสียงทีละโน้ต` |

**Recommendation:** keep the diagnostic mechanics, but separate internal QA wording from student-facing labels. The student-facing version should explain: “โน้ตที่เรียนยังเป็นตัวเดิม แต่เสียงที่เปิดให้ฟังอาจขยับ octave เพื่อให้ได้ยินชัดขึ้นบนมือถือ/ลำโพงเล็ก.”
