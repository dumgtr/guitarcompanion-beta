# Guitar Companion — Month 1 Beta RC1

## Version

Month 1 Beta RC1 (`v3.0.0-m1-beta.1`)

## Curriculum Scope

Month 1 Rhythm Foundation, Weeks 1–4:

- Pulse & 16th Grid
- Syncopation Accent Alignment
- Dynamics & Palm Muting
- Groove Integration

## Audio Engine

Calibrated tri-instrument audio sampler:

- Synth
- Nylon, MIDI 40–76
- Electric, CC0

The retrigger lifecycle uses 12 ms fade-out and 8 ms fade-in.

## Guardrails & Security

Future months (Month 2+) remain locked in normal mode. Isolation is maintained through the shard architecture.

## DevOps Infrastructure

Automated GitHub Actions CI Gate validating JavaScript syntax, the FSL suite (96/96), and the Main Harness (65/65).

Branch protection is unavailable under the current private-repository GitHub plan, so merge approval remains a manual Product Owner gate.
