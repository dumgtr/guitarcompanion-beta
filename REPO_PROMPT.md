# REPO_PROMPT.md

Guitar Companion is a focused 4-week rhythm foundation app.

The user opens the app and should immediately understand:
1. What week they are on
2. What to practice today
3. What lesson to read
4. What homework to complete

Main sections:
- Dashboard
- Lessons
- Practice Lab

Keep the interface calm, simple, and non-overwhelming.
The app should not feel like a big course catalog.
