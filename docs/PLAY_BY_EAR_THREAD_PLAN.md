# Play By Ear Thread Plan
Status: Documentation / Curriculum Thread Strategy

## 1. Core Philosophy & Milestone Progression

Playing by ear is not a single advanced module. For Guitar Companion, it is a long-term pedagogical thread woven into every lesson from Week 0 to Month 10.

The learner should not suddenly "start ear training" in one isolated month. Instead, the app should help the student build a listening pathway step by step: first hearing time, then hearing tonal center, then hearing chord movement, then choosing notes that fit the music.

Core milestone progression:

**ฟังได้ → นับได้ → จับคีย์ได้ → หา root ได้ → เดา progression ได้ → เล่น chord tones ได้ → เติม scale ได้ → improvise ตามเพลงได้**

English reference:

**Listen -> Count -> Find Key -> Find Root -> Guess Progression -> Play Chord Tones -> Add Scale -> Improvise to the track**

This thread must stay practical. Every listening task should answer the question: "What should my hands do on the guitar because I heard this?"

## 2. The Month-by-Month Thread

- **Week 0:** Rhythm vocabulary / Beat 1 / 4/4 / Downbeat-Upbeat. (Establishing the pulse).
  - ผู้เรียนเริ่มจากการฟังเวลา ไม่ใช่ฟังโน้ต
  - เป้าหมายคือฟัง Metronome แล้วนับ 1-2-3-4 ได้มั่นคง
  - Play By Ear thread stage: **ฟังได้ → นับได้**

- **Month 1:** Rhythm ear / groove / strumming / syncopation. (Feeling the subdivisions).
  - ผู้เรียนฟัง Groove และรู้สึกได้ว่าเสียงตกบนเลขหรืออยู่ระหว่างเลข
  - Syncopation ถูกสอนเป็นสิ่งที่ได้ยินและรู้สึกก่อนเป็น pattern ที่ต้องจำ
  - Play By Ear thread stage: **นับได้ → รู้สึก subdivision ได้**

- **Month 2:** Fretboard landmarks / root / octave / major scale formula. (Connecting ears to physical fretboard geography).
  - ผู้เรียนเริ่มผูกเสียงที่ได้ยินเข้ากับตำแหน่งจริงบนคอกีตาร์
  - Root และ Octave ทำให้คำว่า "เสียงบ้าน" ไม่ใช่ทฤษฎีลอยๆ แต่เป็นจุดที่นิ้วหาเจอ
  - Play By Ear thread stage: **จับคีย์ได้ → หา root ได้**

- **Month 3:** Chord tone awareness / triads / arpeggio / 7th / target chord tones. (Hearing inside the chords and anticipating changes).
  - ผู้เรียนเริ่มฟังว่าในคอร์ดมีเสียง 1-3-5 และ 7th ซ่อนอยู่
  - Arpeggio ถูกใช้เพื่อได้ยิน chord tones เคลื่อนไหว ไม่ใช่เพื่อเล่นเร็ว
  - Week 12 เชื่อมไปสู่การเดาการเปลี่ยนคอร์ดและลง target note บน Beat 1
  - Play By Ear thread stage: **เดา progression ได้ → เล่น chord tones ได้**

- **Month 4:** Scale atlas / major, pentatonic, blues scale / connect sound to positions. (Hearing scales as melodic flavors, not just finger boxes).
  - ผู้เรียนเริ่มเติม scale หลังจากมี root และ chord tones แล้ว
  - Scale ถูกสอนเป็นสีของ melody ที่หูจำได้ ไม่ใช่กล่องนิ้วให้ไล่ขึ้นลง
  - Play By Ear thread stage: **เล่น chord tones ได้ → เติม scale ได้**

- **Month 5:** Improvisation foundation / question-answer / motifs / phrase endings. (Vocalizing phrases through the guitar).
  - ผู้เรียนฝึกคิดเป็นวลี ถาม-ตอบ และเว้น space
  - หูต้องนำมือ: ฮัมหรือร้องไอเดียสั้นๆ ก่อนค่อยเล่นบนกีตาร์
  - Play By Ear thread stage: **เติม scale ได้ → พูดประโยคดนตรีได้**

- **Month 6:** Modes as chord colors / Dorian / Mixolydian for bluesman path. (Recognizing specific emotional colors over chords).
  - Modes ไม่ใช่สารานุกรม scale แต่เป็นสีที่ได้ยินเมื่อเล่นทับคอร์ด
  - Dorian และ Mixolydian เป็น priority เพราะพาไปสู่ Blues / Rock / Funk ได้ชัด
  - Play By Ear thread stage: **แยกสีเสียงเฉพาะของคอร์ดได้**

- **Month 7-8:** Blues form, turnarounds, comping, licks, call-response. (Applying the ear to a rigid, predictable musical form).
  - ผู้เรียนใช้หูตามฟอร์ม 12-bar หรือ form ที่คาดเดาได้
  - Call-response, lick placement, comping และ turnaround ถูกผูกกับตำแหน่งใน form
  - Play By Ear thread stage: **เดา form ได้ → ตอบสนองตามเพลงได้**

- **Month 9:** Transcription & play-by-ear workflow. (The active practice of lifting music directly from recordings).
  - ผู้เรียนเริ่มฝึก workflow จริง: ฟัง หยุด ฮัม หา root หา note แล้วตรวจบนกีตาร์
  - Transcription ไม่ใช่การเขียนโน้ตเต็มระบบ แต่คือการดึงเสียงจากเพลงมาเข้ามือ
  - Play By Ear thread stage: **ยกเพลงจาก recording ได้**

- **Month 10:** Song application / fingerstyle or arrangement layer. (Complete musical independence).
  - ผู้เรียนเอาทุกอย่างมารวมเป็นการเล่นเพลงจริง: rhythm, root, chord tones, scale color, phrasing, arrangement layer
  - หูนำการเลือก voicing, bass movement, melody note และ dynamic layer
  - Play By Ear thread stage: **improvise ตามเพลงได้ → จัดเรียงเพลงเองได้**

## 3. Implementation Guardrails

- Every new lesson drafted in the future MUST reference where it sits on this thread.
  - Each draft should include a short "Play By Ear Thread Position" note.
  - This note should explain whether the lesson is training pulse, root hearing, chord movement, chord tones, scale color, phrasing, transcription, or arrangement.

- Audio labs (like `chordSoundLabs` and `earTrainingLabs`) must be utilized consistently across months to support this thread.
  - `chordSoundLabs` should support practical chord quality, progression, and target-note hearing tasks.
  - `earTrainingLabs` can exist as a UI pattern, but the learning goal must always connect back to the fretboard.
  - If audio fails, every lab needs a text fallback that tells the learner how to reproduce the listening task on a real guitar.

- Avoid treating ear training as a purely academic interval-recognition test; always tie it back to practical fretboard application.
  - Bad direction: "Identify this interval in isolation."
  - Better direction: "ฟังว่าโน้ตนี้อยากกลับ Root ไหม แล้วหาตำแหน่ง Root บนสาย 5 หรือ 6"
  - Best direction: "ฟัง progression ก่อน แล้วเลือก chord tone ที่จะลง Beat 1 บนคอร์ดถัดไป"

- Play By Ear should remain incremental and non-intimidating.
  - Week 0 asks only: "Can you hear and count the pulse?"
  - Month 2 asks: "Can you hear home and find Root?"
  - Month 3 asks: "Can you hear the chord and land on a chord tone?"
  - Later months ask more, but only after the previous layer is stable.

- Do not create a separate "Play By Ear Module" unless a future product decision explicitly changes the curriculum model.
  - The current strategy is thread-based integration, not roadmap expansion.
  - This protects the student from cognitive overload and keeps the app feeling like a daily teacher companion.
