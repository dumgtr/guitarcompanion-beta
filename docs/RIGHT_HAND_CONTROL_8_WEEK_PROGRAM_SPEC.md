# Right-Hand Control — 8-Week Program Spec

Status: Documentation Only / Pre-Implementation Spec

This document defines the 8-week program for "Right-Hand Control". It focuses on essential picking techniques tailored for learners aiming to improve their rhythm, accuracy, and dynamic control.

## Overview
This program introduces four new techniques integrated into an 8-week structure. It emphasizes precision and groove without overcomplicating the fundamentals.

- **Target Audience:** Learners who understand basic alternate picking and need to refine their right-hand mechanics.
- **Duration:** 8 Weeks
- **Structure:** Guided week-by-week practice routines.

## Core Techniques

### 1. Inside vs. Outside Picking
- **Placement:** Placed early, after the learner understands basic alternate picking.
- **Mechanics:** Begin with adjacent string pairs (e.g., strings 3 and 4).
- **Display:** Use explicit string numbers and pick directions (Down/Up) instead of relying solely on terms like "upper/lower string" which can be ambiguous on screen.

### 2. Rhythmic Displacement
- **Placement:** Inside the Rhythm & Groove portion of the program.
- **Mechanics:** Focus on continuous sixteenth notes with rotating accent positions:
  - Beat (1, 2, 3, 4)
  - e
  - &
  - a

### 3. Dynamic Staircase
- **Placement:** Inside the Rhythm & Groove portion.
- **Mechanics:** Use five practical dynamic levels:
  - **pp** (Pianissimo)
  - **p** (Piano)
  - **mp** (Mezzo-piano)
  - **f** (Forte)
  - **ff** (Fortissimo)
- **Goal:** Train gradual crescendo and decrescendo while preserving clean attack and timing.

### 4. Hybrid Picking (Optional Track)
- **Placement:** Introduced in Week 7 as an optional track.
- **Mechanics:** The pick handles bass strings, while middle and ring fingers handle higher strings.
- **Application:** Explain Blues, Country, and Modern Pop applications.
- **Constraint:** Must not replace the core alternate-picking path.

### 5. Economy Picking (Isolated)
- **Constraint:** Keep Economy Picking clearly separated from alternate-picking fundamentals.
- **Placement:** Separate focused module or clearly isolated advanced section at the end of the program. Do not combine the two mechanics before the learner understands alternate picking and string crossing.

## Program Roadmap

### Weeks 1–2: Fundamentals and String Crossing
- Picking grip, motion, and basic alternate picking review.
- **Pro Drill:** Inside/Outside String Crossing Drill (Strings 3 and 4).

### Weeks 3–4: Rhythm and Dynamics
- Rhythm, accents, groove, and dynamics.
- **Pro Drill:** Rhythmic Displacement (rotating accents on 16th notes).
- **Pro Drill:** Dynamic Staircase (pp to ff).

### Weeks 5–6: Precision and Speed
- Accuracy, palm muting, string crossing refinement.
- Controlled speed building.

### Week 7: Optional Techniques
- **Optional Track:** Hybrid Picking Introduction (Blues, Country, Pop context).

### Week 8: Application and Wrap-up
- Musical application of learned techniques.
- Final routine integration.

### Post-Program / Advanced
- **Economy Picking:** Separate focused module for advanced mechanics.
