# Rhythm Notation Starter Spec
Status: Documentation / Mini Course Draft Spec

## 1. Mini Course Identity

Mini course title: **Rhythm Notation Starter**

Thai title: **อ่านค่าจังหวะ: ตัวดำ ตัวหยุด และจังหวะตก-ยก**

Placement: Future Mini Course Shelf inside Practice Room / support area

Status: Draft / spec-planned only

This mini course is optional support material. It is not Month 0, not a new Week, and not required roadmap progression.

Schema alignment note: older planning language may refer to daily `lessons[]`, but the accepted Mini Course renderer contract uses `modules[]` under the root-level `miniCourses[]` payload.

## 2. Purpose

Rhythm Notation Starter ช่วยให้ผู้เรียนอ่านค่าจังหวะพื้นฐานก่อนหรือระหว่าง Month 1 ได้อย่างเป็นขั้นตอน โดยยึดหลัก:

เห็นสัญลักษณ์ -> นับออกเสียง -> ตบมือ -> ค่อยเล่นบนกีตาร์

บทนี้ไม่ได้แทนที่ Note Value Cheatsheet ที่อยู่ใน Reference Shelf แต่เปลี่ยนข้อมูลอ้างอิงให้กลายเป็นแบบฝึก 7 วันสั้น ๆ

## 3. Learner Fit

เหมาะสำหรับผู้เรียนที่:

- อ่านเลขบน TAB ได้บ้าง แต่ยังไม่รู้ว่า rhythm บอกเวลาอย่างไร
- นับ 1 2 3 4 ได้ แต่หลุดเมื่อต้องมี rest
- สับสนระหว่าง downbeat / upbeat และ downstroke / upstroke
- อยากเตรียมตัวก่อนเข้า Week 1 Pulse & 16th Grid
- อยากทบทวนแบบไม่ต้องอ่านคู่มือยาว

## 4. Scope

7-day optional mini course, 8-10 minutes per day.

Core scope:

- Beat
- Bar
- 4/4
- Quarter note
- Quarter rest
- Eighth notes
- Downbeat / Upbeat
- Downstroke / Upstroke connection
- Rhythm above simple TAB
- Metronome challenge

## 5. Required 7-Day Outline

### Day 1: Beat, Bar, and 4/4

Goal: รู้ว่าเพลงมี pulse และใน 4/4 เรานับ 1 2 3 4 แล้วขึ้นห้องใหม่

Practice:

- เปิด Metronome 60 BPM
- นับ 1 2 3 4 วน 1 นาที
- ตบมือเฉพาะเลข 1
- ตบมือทุกเลข

Self-check:

- นับได้โดยไม่เร่ง
- รู้สึกได้ว่า Beat 1 คือจุดเริ่มห้องใหม่

### Day 2: Quarter Note and Steady Counting

Goal: เข้าใจว่าตัวดำคือเล่น 1 ครั้งต่อ 1 beat ในบทนี้

Practice:

- Count: `1 2 3 4`
- Clap: `ตบ ตบ ตบ ตบ`
- Guitar: mute strings แล้ว downstroke บนทุกเลข

Self-check:

- เสียงตบหรือดีดตรงกับ click
- ไม่รีบไปก่อน Metronome

### Day 3: Quarter Rest and Silent Counting

Goal: เข้าใจว่าตัวหยุดคือเงียบ แต่ count ยังเดินต่อ

Practice:

- Count: `1 2 3 4`
- Clap: `ตบ เงียบ ตบ เงียบ`
- Guitar: strum on 1 and 3, mute/stop on 2 and 4

Self-check:

- เงียบตรง rest ได้จริง
- ปากยังนับต่อแม้มือหยุด

### Day 4: Eighth Notes and "1 & 2 &"

Goal: รู้ว่า `&` อยู่ระหว่างเลขหลัก และยังต้องอยู่ใน time

Practice:

- Count: `1 & 2 & 3 & 4 &`
- Clap ทุกตัวเลขและทุก `&`
- เท้าเคาะเฉพาะเลข 1 2 3 4

Self-check:

- ปากนับ `&` ได้เท่ากับช่องเลข
- เท้าไม่หลุดไปตามมือ

### Day 5: Downbeat / Upbeat and Downstroke / Upstroke Connection

Goal: แยกตำแหน่งเวลาออกจากทิศทางมือขวา

Practice:

- Count: `1 & 2 & 3 & 4 &`
- Feel: `ตก ยก ตก ยก ตก ยก ตก ยก`
- Strum: `ลง ขึ้น ลง ขึ้น ลง ขึ้น ลง ขึ้น`

Teacher note:

Downbeat คือตำแหน่งเวลา ส่วน downstroke คือทิศทางมือ ในแบบฝึกเริ่มต้นเรามักจับคู่กันเพื่อให้จำง่าย แต่สองคำนี้ไม่ใช่สิ่งเดียวกัน

### Day 6: Reading Rhythm Above Simple TAB

Goal: เข้าใจว่าเลขใน TAB บอกว่าเล่นอะไร แต่ rhythm บอกว่าเล่นเมื่อไรและยาวแค่ไหน

Practice:

```text
Count:  1   &   2   &   3   &   4   &
Rhythm: ♩       ♪   ♪       ♩
TAB:    E|--0-------0---0-------0---|
```

Self-check:

- อ่านเลข 0 เป็นสายเปิดได้
- อ่าน rhythm ก่อนดีดจริงได้

### Day 7: Mini Rhythm Reading Challenge with Metronome

Goal: รวม count, clap, rest, and simple TAB reading เข้าด้วยกัน

Practice:

- Set Metronome 60 BPM
- Read count line aloud
- Clap rhythm
- Mute strings and strum rhythm
- Play simple open-string TAB

Self-check:

- นับไม่หลุด
- rest เงียบจริง
- เล่นช้ากับ Metronome ได้โดยไม่รีบ

## 6. Avoid For Now

- Sixteenth-note deep theory
- Dotted notes
- Ties
- 6/8 full lesson
- Advanced rhythmic notation
- Full staff-reading course
- Sight-reading curriculum
- Copying the whole Note Value Cheatsheet into the mini course

## 7. Relationship To Existing Content

Reference Shelf:

- Note Value Cheatsheet remains the full reference
- TAB Handbook remains the TAB symbol reference
- Mini course may link to those references but must not duplicate them

Week 0:

- Week 0 teaches rhythm survival at prelude level
- Rhythm Notation Starter gives optional 7-day support for learners who need more repetition

Month 1:

- Week 1 remains Pulse & 16th Grid
- Week 2 remains Syncopation
- Mini course supports Month 1, but does not become part of Month 1 completion

## 8. Renderer Requirements

Future renderer should support:

- Mini course landing card
- Day-by-day lesson view
- Count map rows
- Clap task card
- Guitar task card
- Self-check checklist
- Related reference buttons
- Completed day indicator

No production renderer exists yet. Next step after approval is renderer planning, not immediate UI implementation.

## 9. Progress / Reset Decision

- Rhythm Notation Starter uses isolated mini-course progress keys.
- Main Month reset does not clear Rhythm Notation Starter progress.
- Rhythm Notation Starter reset is separate.
- If completed days > 3 of 7, require type-to-confirm before clearing.
- Confirmation phrase: `RESET MINI COURSE`
