# Curriculum Roadmap

เอกสารนี้คือแหล่งอ้างอิงหลักของหลักสูตรระยะยาวสำหรับ Guitar Companion
ใช้เพื่อวางทิศทางการสอนในอนาคตเท่านั้น ไม่ใช่รายการ module ที่ต้องแสดงในหน้าเว็บตอนนี้

## Project Identity

Guitar Companion คือ personal guitar learning companion ภาษาไทยเป็นหลัก เริ่มจาก webapp ส่วนตัวสำหรับผู้เรียนหนึ่งคน และอาจพัฒนาให้แชร์กับผู้เรียนคนอื่นที่ต้องการเส้นทางคล้ายกันในอนาคต

แอปนี้ไม่ใช่ LMS ไม่ใช่ marketplace และไม่ใช่สารานุกรมทฤษฎีดนตรี เป้าหมายคือให้รู้สึกเหมือนมีครูกีตาร์ส่วนตัว ห้องซ้อมส่วนตัว และเส้นทางการฝึกที่พาผู้เรียนจากพื้นฐานที่เคยข้ามไป ค่อย ๆ เติบโตไปสู่การเป็นนักกีตาร์สาย blues-oriented ที่เล่นได้มั่นใจขึ้น

## Target Learner

ผู้เรียนเป้าหมายคือคนที่เคยเล่นกีตาร์มาแล้ว แต่พื้นฐานบางอย่างไม่แน่น เพราะอาจเคยข้ามเรื่องสำคัญในช่วงเริ่มต้น ชอบ blues, rock, acoustic และเรื่อง guitar tone ต้องการกลับมา rebuild fundamentals อย่างเป็นระบบ โดยไม่อยากอ่านทฤษฎีแห้ง ๆ แบบตำรา ต้องการคำแนะนำรายวันว่า “วันนี้ควรซ้อมอะไร” และต้องการแรงจูงใจให้กลับมาฝึกต่อเนื่อง

## Learning Philosophy

หลักสูตรควรให้ความรู้สึกเหมือนครูสอนตัวต่อตัวมากกว่าคอร์สออนไลน์ทั่วไป ทุกบทควรตอบคำถามว่า ฟังอะไร รู้สึกอะไร เล่นอย่างไร เช็กตัวเองอย่างไร และนำไปใช้กับเพลงจริงอย่างไร

Blues เป็นเส้นเรื่องที่วนกลับมาใช้ตลอดหลักสูตร แต่ไม่ควรเปลี่ยนทั้งคอร์สให้เป็น blues-only course ผู้เรียนควรได้พื้นฐานกว้างพอสำหรับ rhythm, fretboard, scale, harmony, chord progression, fingerstyle, improvisation และ style applications อื่น ๆ ด้วย

หลักสูตรเป็น open-ended path ระยะ 18-24 เดือน หรือประมาณ 2 ปีได้ ไม่จำเป็นต้องจบใน 12 สัปดาห์

## Core Learning Path

1. Foundation Reset
2. Rhythm
3. Fretboard
4. Scale
5. Harmony
6. Chord Progressions
7. Blues Thread
8. Fingerstyle
9. Improvisation

## 0. Week 0: Foundation Reset

### Purpose

Week 0 คือด่านตั้งหลักสำหรับคนที่เล่นกีตาร์มาก่อน แต่เคยข้ามพื้นฐานหลายเรื่อง ไม่ควรเรียกว่า beginner only เพราะผู้เล่นระดับกลางก็อาจต้องกลับมาเก็บเรื่องเหล่านี้ให้แน่นได้ Week 0 อาจใช้เวลามากกว่า 7 วันได้ตามสภาพจริงของผู้เรียน

### 1. Guitar Orientation

- ส่วนต่าง ๆ ของกีตาร์
- เลขสาย 1-6
- high string กับ low string
- fret 0 หรือ open string
- fret 12 เป็น octave
- fret markers และ dot landmarks

### 2. Tuning

- Standard tuning: E A D G B E
- วิธีใช้ tuner
- ทำไมต้องตั้งสายก่อนซ้อมทุกครั้ง

### 3. Clean Note Production

- กดโน้ตให้เสียงชัด
- buzz
- muted/dead notes
- วางนิ้วใกล้ fret
- แยกให้ออกว่าเสียงเสียมาจากอะไร: กดไม่ถึง, วางนิ้วผิด, สายโดน mute หรือมือเกร็งเกินไป

### 4. Picking / Strumming Mechanics

- pick grip
- downstroke
- upstroke
- alternate picking
- ข้อมือผ่อนคลาย
- แบบฝึก open-string picking เบื้องต้น

### 5. Muting Basics

- left-hand muting
- right-hand muting
- ลดเสียงสายที่ไม่ต้องการ
- สำคัญมากสำหรับกีตาร์ไฟฟ้าและเสียง gain

### 6. Chord Diagram Survival

- X = ไม่ต้องเล่นสายนั้น
- O = open string
- หมายเลขนิ้ว 1 2 3 4
- root note
- fret indicator
- คอร์ดพื้นฐาน เช่น Em, Am, C, G, D

### 7. TAB Survival

- เส้นสายกีตาร์ใน TAB
- ตัวเลข fret
- 0 = open string
- h = hammer-on
- p = pull-off
- / = slide
- b = bend
- ~ = vibrato

### 8. Fretboard Survival

- E-F ห่างกัน 1 fret
- B-C ห่างกัน 1 fret
- natural notes ส่วนใหญ่ที่เหลือห่างกัน 2 frets
- fret 12 คือโน้ต open string เดิมที่สูงขึ้นหนึ่ง octave
- สาย 6 และสาย 1 เป็น E เหมือนกัน

### 9. Practice Method

- ช้าและชัด ดีกว่าเร็วแต่เละ
- Metronome คือกระจก ไม่ใช่ศัตรู
- อัดเสียงตัวเองเพื่อฟังความจริง
- ซ้อม 10 นาทีแบบมีเป้าหมาย ดีกว่าเล่นเรื่อย ๆ แบบหลุดโฟกัส
- ทุก session ควรมีเป้าหมายเดียวที่ชัด

### 10. Guitar / Gear Survival

- pick thickness
- capo basics
- สายเก่าและผลต่อเสียง
- action height
- ใช้ clean tone เพื่อตรวจเทคนิค
- gain เยอะเกินไปอาจซ่อนความผิดพลาดและเพิ่ม noise

### 11. Basic Fingerpicking Literacy

- อ่าน pattern ด้วยเลขสาย เช่น 5-4-3-2
- เข้าใจว่า fingerpicking คือ rhythm ที่กระจายลงบนหลายสาย
- เล่น pattern ง่าย ๆ บนคอร์ดเดียวให้เสียงนิ่งก่อน

### 12. First Song Challenge

ท้าย Week 0 ควรมี simple song หรือ song-like exercise ที่รวมทักษะพื้นฐานเข้าด้วยกัน เป้าหมายคือให้ผู้เรียนตั้งสายได้ อ่าน chord diagram ได้ อ่าน TAB ง่าย ๆ ได้ เล่น rhythm หรือ picking pattern ง่าย ๆ ได้ และอัด take สั้น ๆ เพื่อตรวจตัวเอง

### Week 0 Status Labels

- ยังไม่เริ่ม
- กำลังฝึก
- เริ่มนิ่ง
- ผ่านแล้ว

## 1. Month 1: Rhythm Foundation

Month 1 ยังคงเป็นขอบเขตที่มองเห็นในแอปปัจจุบัน เป้าหมายคือทำให้ผู้เรียนมี rhythm foundation ที่ไว้ใจได้ ไม่ใช่แค่รู้ pattern แต่ฟัง Pulse ออก รู้สึก Groove ได้ และเล่นกับ Metronome โดยไม่หลุด

### Visible Weeks

- Week 1: Pulse & 16th Grid
- Week 2: Syncopation
- Week 3: Dynamics & Palm Muting
- Week 4: Groove Integration

### Lesson Depth Improvements

- daily self-check
- troubleshooting / common mistakes
- BPM targets
- visual rhythm grids
- rhythm ear training
- mini song application
- Metronome-based practice
- teacher-style Thai explanations
- ตัวอย่างการใช้งานใน blues, funk และ pop

### Week 1: Pulse & 16th Grid

- Pulse คือจังหวะหลักที่เดินอยู่ตลอดเพลง เหมือนการเคาะเท้าตามเพลง
- แยกให้ออกระหว่าง Pulse กับ rhythm
- 16th grid: 1 e & a
- มือขวาควรเคลื่อนไหวสม่ำเสมอ ไม่หยุดตามใจ pattern
- เริ่มประมาณ 60 BPM

### Week 2: Syncopation

- Syncopation คือการเน้นหรือเล่นในตำแหน่งที่ไม่ใช่ beat ตรง ๆ
- ฝึก off-beat และการเล่นบน “&”
- แยกให้ออกระหว่าง syncopation กับการหลุด tempo
- เพิ่ม rhythm ear training เพื่อให้ฟังจุดตกของจังหวะออก
- BPM เป้าหมายประมาณ 50-80

### Week 3: Dynamics & Palm Muting

- เล่นเบา-ดังให้ตั้งใจ ไม่ใช่ปล่อยให้มือหนักเอง
- Palm Mute ต้องมี pitch ไม่ใช่เสียงตันตาย
- ฝึก light attack กับ strong attack
- troubleshooting: dead sound, buzz, uneven volume
- BPM เป้าหมายประมาณ 60-70

### Week 4: Groove Integration

- รวม Pulse, Syncopation, Dynamics และ Palm Mute
- สร้าง Groove ที่รู้สึกเป็นเพลง ไม่ใช่แค่แบบฝึกหัด
- มี mini song application
- มี final rhythm assessment
- BPM เป้าหมายประมาณ 70-75

## 3. Scale Handbook / Scale Atlas

Scale section ควรพัฒนาเป็น module แบบหนังสือคู่มือ ไม่ใช่แค่รูป diagram เป้าหมายคือสอนตั้งแต่วิธีอ่าน scale diagram ไปจนถึงการใช้ scale ให้เป็นดนตรีจริง

### Chapter 1: How to Read Scale Diagrams

- strings
- frets
- finger numbers
- root notes
- fret markers
- open strings
- diagram orientation

### Chapter 2: Movable Patterns

- shape เดิมสามารถย้ายไป key อื่นได้
- root เป็นตัวกำหนดชื่อ scale
- ตัวอย่าง: C Major pattern ย้ายไป root D จะกลายเป็น D Major

### Chapter 3: Major Scale Foundation

- formula: W W H W W W H
- scale degrees: 1 2 3 4 5 6 7
- C Major = C D E F G A B
- ร้องก่อนเล่น เพื่อให้หูนำมือ
- เล่นช้า ๆ พร้อม rhythm

### Chapter 4: Major Scale Patterns

- หลาย positions
- pattern คือแผนที่ ไม่ใช่ดนตรีโดยตัวมันเอง
- เชื่อม pattern ทีละน้อย

### Chapter 5: CAGED Connection

- chord shapes เชื่อมกับ scale shapes
- เล่น scale รอบ chord shapes
- เป็นพื้นฐานต่อไปสำหรับ triads, chord tones และ soloing

### Chapter 6: Pentatonic Scale

- minor pentatonic
- major pentatonic
- 5 positions
- root notes
- Box 1 และ connected boxes
- ใช้กับ blues, rock และ country

### Chapter 7: Blues Scale

- minor pentatonic + b5
- blue note
- ใช้กับ phrasing, bends, vibrato และ space
- ห้ามฝึกแค่วิ่งขึ้นลง scale โดยไม่สร้างประโยคดนตรี

### Chapter 8: Natural Minor / Relative Major-Minor

- C Major และ A Natural Minor ใช้โน้ตชุดเดียวกัน
- โน้ตเหมือนกัน แต่ tonal center ต่างกัน
- ใช้ได้บ่อยใน pop และ rock

### Chapter 9: Scale Application

- ใช้ scale กับ Backing Track
- phrase building
- rhythm-first soloing
- target notes
- space
- motifs
- ทำไมการวิ่ง scale อย่างเดียวถึงยังไม่ฟังเป็นเพลง

### Chapter 10: Scale Practice Pages

แต่ละหน้า scale ควรมี:

- scale name
- formula
- notes in a key
- root positions
- diagram
- use cases
- practice routine
- lick example
- common mistakes
- self-check

### Core Scales

- Major Scale
- Minor Pentatonic
- Major Pentatonic
- Blues Scale
- Natural Minor

### Intermediate Later

- Dorian
- Mixolydian
- Harmonic Minor

### Reference Only / Future

- Diminished
- Melodic Minor
- Exotic scales

## 5. Chord Colors Lab

ควรวางหลัง Month 3: Chord Tone & Arpeggio Foundation เพื่อให้ผู้เรียนเข้าใจ structure ก่อน แล้วค่อยเติม mood, atmosphere และ richness ด้วย chord colors

### Purpose

สอน beautiful chords, color chords, extended chords และ open voicings โดยเชื่อมกับเพลงจริงและการแต่งเพลง ไม่ใช่ให้จำชื่อคอร์ดอย่างเดียว

### Include

- maj7
- m7
- 6
- add9
- add11
- sus
- slash chords ในภายหลัง
- open voicings
- open string color
- voice leading basics

### Example

Basic progression:

- B - G#m - E - F#

Colored progression:

- Bmaj7 - G#m(add9,11) - E6 - F#add11

หลักการสอน:

- chord progression = โครงสร้าง
- chord color = mood / atmosphere / richness

เชื่อมต่อกับ acoustic pop, fingerstyle, soul, gospel และ songwriting

## 6. Blues Thread and Blues Core

เป้าหมายระยะยาวรวมถึงการเติบโตเป็นนักกีตาร์สาย blues-oriented แต่หลักสูตรไม่ควรเป็น blues-only course

### Blues Thread

ใช้ blues เป็น application thread ตลอดหลักสูตร:

- Rhythm: shuffle, swing, 12/8, comping
- Fretboard: roots สำหรับ A, E, D, G blues
- Harmony: I-IV-V, dominant 7th, 12-bar form
- Scales: minor pentatonic, major pentatonic, blues scale
- Improvisation: question and answer, licks, target notes
- Technique: bends, vibrato, slides, muting

### Dedicated Blues Core Module Later

- 12 Bar Blues
- I-IV-V
- Dominant 7th chords
- shuffle rhythm
- slow blues / 12/8 feel
- boogie rhythm
- turnarounds
- endings
- count-in
- band cues
- comping
- Blues Jam Survival
- เล่นเพลงที่ไม่รู้จักโดยอ่าน key, form, feel และ role
- minor pentatonic
- major pentatonic
- blues scale
- question and answer phrasing
- basic blues licks
- chord tones และ target notes ในภายหลัง

### Blues Jam Survival

ผู้เรียนควรรอดใน jam ได้แม้ไม่รู้เพลง โดยถามและฟังให้เป็น:

- key อะไร
- form อะไร
- 12-bar หรือไม่
- shuffle หรือ straight
- กำลังเล่น role ไหน
- rhythm, fill หรือ solo
- turnaround อยู่ตรงไหน
- เพลงจบอย่างไร

## 9. Improvisation

Improvisation ควรวางหลัง fretboard, scale, harmony และ blues basics เพราะการ improvise ที่ดีไม่ใช่การวิ่ง scale แบบสุ่ม แต่คือ real-time composition ที่ใช้ rhythm, phrase, melody, chord awareness และ vocabulary

### Include

- phrase building
- question and answer
- space
- motifs
- rhythm-first soloing
- target notes
- chord tones
- triads
- arpeggios
- basic licks
- playing over chord changes
- major/minor pentatonic choice
- Hotel California-style triad/arpeggio fragments เป็น future application

### Thinking Like a Player

ผู้เล่นที่ดีมักคิดระหว่างเล่นว่า:

- ตอนนี้คอร์ดอะไร
- ควรลงที่โน้ตไหน
- phrase นี้ตอบ phrase ก่อนหน้าอย่างไร
- rhythm แบบไหนทำให้ประโยคนี้ฟังเป็นดนตรี

## 10. Technique Lab

Technique Lab ควรแยกจาก main roadmap เพื่อไม่ให้หลักสูตรหลักกลายเป็นการฝึกนิ้วอย่างเดียว

### Include

- chromatic exercise
- spider exercise
- finger independence
- alternate picking
- string crossing
- basic speed control
- muting drills

### Future Electives Only

- speed picking
- sweep picking
- tapping
- advanced legato
- string skipping
- hybrid picking advanced

ไม่ควรใส่ advanced shred techniques ลงในช่วงต้นของ main curriculum

## Implementation Guardrails

- ห้าม expose future modules ทั้งหมดใน app UI ปัจจุบัน
- Week 0 ควรถูก documented ก่อน แล้วค่อย implement ภายหลัง
- Month 1 ยังเป็น visible learning scope ปัจจุบัน เว้นแต่มีคำสั่งเปลี่ยนชัดเจน
- future modules เป็น documented but hidden
- ใช้ Thai-first teacher-style explanations
- prefer learning flow: Watch / Learn / Practice / Self-check / Apply
- หลีกเลี่ยง feature creep
- อย่าเปลี่ยนแอปให้เป็น theory encyclopedia
- อย่าเปลี่ยนแอปให้เป็น blues-only course
- รักษาความรู้สึกแบบ personal companion
- ทำงานแบบ small iterative updates
