# Nylon Guitar Sample Attribution

These nylon/classical guitar samples are derived from the classical guitar
multisample collection created by quartertone and distributed through the
tonejs-instruments project prepared by Nicholaus P. Brosowsky.

Source references:
- Original Freesound pack: https://freesound.org/people/quartertone/packs/11573/
- tonejs-instruments: https://github.com/nbrosowsky/tonejs-instruments
- Verified upstream revision: `622c2f1c32c8cfce4158ddc3eb26e518ddef37e5`
- Upstream sample directory: `samples/guitar-nylon/`

Modifications in Guitar Companion:
- Selected subset of source samples
- Playback through the native Web Audio sampler
- Real-time pitch transposition using playbackRate
- Measured cross-bank gain correction documented in
  `reports/FSL_AUDIO_CALIBRATION_V1.md`

These samples were not copied from muted.io.
